# Campminder Brand Architecture

A working tool, not a slide. Use it when a naming question, a new feature, or an acquisition puts a brand decision on the table. It turns the strategy into rules the whole team can apply the same way.

> Working draft v1. The rules below are scaffolded. We write the real language together.

## Ask first

Before deciding anything, get the context that changes the answer:

- [ What is the product decision underneath this? ]
- [ Who is the audience, and does an existing brand already own them? ]
- [ Is this a lasting brand or a feature that will fold into a platform? ]

## The rules

1. **Semantic and contextual naming.**
   [ Rule to write. Names should carry meaning in the context a customer meets them, not borrow equity they have not earned. ]

2. **Brand follows product decisions.**
   [ Rule to write. Product strategy sets what is possible for a brand. If a product folds into a platform, its brand becomes a feature name, not a standalone brand. ]

3. **Spend a set share of the marketing budget on naming.**
   [ Rule to write. Name the target percentage and what it buys, so naming is funded on purpose instead of by leftovers. ]
