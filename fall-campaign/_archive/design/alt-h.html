Alternate H Specimen

Built on the way a type foundry site works. Every headline is set to fill its row edge to edge, and a thin metadata strip runs underneath carrying the label, the lede, and the dated provenance. The platform is a specimen list, one module per full-width row. There is no rail: a sticky standing strip under the nav holds the duration claim, the Unpack possible mark, and the call to action. Reading copy runs General Sans here, which is the direct A/B against Alternate G.

Two things to know. Every date is a placeholder, same as Alternate G. And I could not load fontshare.com in this session, so the read on it is from memory rather than from the live site. Treat the Fontshare reference as unverified.

What came from the foundry model. Type set to fill the measure rather than to a fixed scale, so the headline size changes with the sentence and the page never feels templated. A metadata strip under every specimen, which is where the dated provenance now lives instead of a lone footnote. The platform list is the font-family list: one name per full-bleed row, huge, with the small stuff pushed to the right edge. Everything else stripped out, so the type is doing the work. Every date is a placeholder, and the specimen sizes are eyeballed at 1440 rather than fitted, which production would need to solve with a fit script.
